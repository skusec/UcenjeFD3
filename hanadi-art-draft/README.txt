HANADI RAŠIĆ — RADNI WEB KONCEPT

Kako otvoriti projekt u VS Codeu:
1. Raspakiraj ZIP.
2. U VS Codeu odaberi File > Open Folder.
3. Otvori mapu "hanadi-rasic-art-draft".
4. Otvori index.html.
5. Za najjednostavniji pregled: desni klik na index.html > Open with Live Server
   (ako imaš Live Server ekstenziju).
6. Bez Live Servera možeš i dvokliknuti index.html i otvoriti ga u browseru.

Datoteke:
- index.html   = struktura stranice
- style.css    = dizajn i responsive layout
- script.js    = filter galerije, modal, mobilni meni i demo forma
- assets/      = fotografije i radovi

NAPOMENE ZA IDUĆU VERZIJU:
- dopuniti službene nazive svih radova
- upisati tehnike i dimenzije
- označiti dostupno / prodano / rezervirano
- dodati cijene ako ih Hanadi želi javno prikazivati
- dodati pravi kontakt
- zamijeniti / dopuniti fotografije kvalitetnijim frontalnim fotografijama radova
- po želji dodati posebnu stranicu za svaki rad
